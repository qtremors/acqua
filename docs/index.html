Credits & Acknowledgements

Acqua is built on open-source foundations and open web standards.

Runtime libraries & components

Acqua is built with Kotlin and Jetpack Compose on Android. Thanks to the maintainers of AndroidX, Jetpack Compose, Material 3, Kotlin, OkHttp, youtubedl-android, yt-dlp, FFmpeg, Python, and QuickJS-Android.

Website & design

The project website is designed with DM Sans, Manrope, Lucide, and Simple Icons.

Each project remains the property of its respective authors and is used under its own license. Full runtime license details are available inside Acqua under Settings → App information → Open-source notices.
